## Descripción del Proyecto

[cite_start]Este repositorio contiene los datos y el código de análisis econométrico para el Trabajo de Fin de Máster (TFM) [cite: 87-661]. El análisis examina el impacto del transporte intermodal ferroviario en el PIB per cápita en 23 países de la UE durante el período 2015-2023.

[cite_start]La contribución metodológica clave es el diagnóstico de la Dependencia Transversal (CSD) y la aplicación de un modelo de Efectos Comunes Correlacionados (CCE) [cite: 422-432, 652-653].

## Contenido del Repositorio

1.  [cite_start]**`FINAL_CORREGIDO_ANALISIS_TFM_EC_3.ipynb`**: El *script* completo (Google Colab) que contiene todo el proceso de limpieza, análisis, diagnóstico (Hausman, CSD) y estimación de los modelos (FE, DK, CCE) [cite: 1-661].
2.  **`FNL_1_CLEAN_LINEAL_DATA_COOP_25.xlsx`**: La base de datos maestra utilizada en el análisis, con datos de Eurostat.
